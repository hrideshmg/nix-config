## Folder Structure

- **base/**: Essential cross-host programs and configurations
- **hyprland/**: Hyprland WM and tightly coupled tools/programs
- **overrides/**: Reusable special program configurations. 

Note that the overrides folder is used for special reusable configurations. For host-specific applications which do not require special configuration, the `/users/<username>/home.nix` file can be used.
